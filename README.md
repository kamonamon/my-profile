# KAMONAMON | Creative Design Studio & Web Development Portfolio

A modern, high-performance, and responsive landing page and portfolio website built for **KAMON GRAPHICS AND DEVELOPMENTS**. Designed to showcase professional web applications, creative branding, graphic design, and motion graphics services, featuring a direct integration with WhatsApp for seamless client project bookings.

---

## 🚀 Features

* **Sleek, Dark-Themed UI:** Crafted with custom CSS variables, subtle radial gradients, glassmorphism effects, and a modern typography hierarchy.
* **Interactive Project Showcase:** Visual stage layout highlighting creative brand emblems and monograms.
* **Comprehensive Service Grid:** Clean cards detailing services ranging from full-stack web applications and logo design to 3D text and motion graphics.
* **Streamlined Order Process:** Clear 4-step workflow explaining the design process from concept brief to final delivery.
* **Direct WhatsApp Integration:** Built-in form submission logic that formats project details (name, service, deadline, budget, and description) and instantly redirects clients to WhatsApp for quick communication.
* **Fully Responsive:** Optimized for mobile phones, tablets, and desktop displays with a toggleable mobile navigation menu.

---

## 🛠️ Tech Stack

* **Markup:** HTML5 (Semantic elements, accessibility attributes)
* **Styling:** Vanilla CSS3 (CSS Grid, Flexbox, Custom Properties, Responsive Media Queries)
* **Scripting:** Vanilla JavaScript (ES6+, DOM Manipulation, Event Handling)
* **Integrations:** WhatsApp Click-to-Chat API
